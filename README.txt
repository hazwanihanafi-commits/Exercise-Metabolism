# TCE504 Exercise Metabolism — Visual Digital Textbook

Files:
- index.html — page structure/content
- style.css — visual styling
- script.js — interactions, quizzes, animations, Exam Prep Mode and tracking logic

## On iPhone
1. Upload these files to a GitHub repository.
2. Open the repository in GitHub.
3. Edit `index.html`, `style.css`, or `script.js` separately.
4. For a live website, enable GitHub Pages from Settings → Pages.

## Important
Keep all three files in the same folder. If you later add images, create an `images` folder and reference them from the HTML/CSS.
